Objetivo

Cargar cualquier OBJ desde la linea de comandos, recentrarlo, rotarlo y trasladarlo en los tres ejes y preparar la demo del logo 42 con tonos grises y giro automatico sobre su centro.

1. Ruta de entrada

./scop
./scop resources/42.obj
./scop resources/teapot2.obj

El cubo es el valor por defecto. Cambiar el modelo no requiere recompilar.

2. Recentrar antes de transformar

Si el OBJ esta lejos del origen, rotarlo directamente produce una orbita. center_mesh() calcula:

center = (min + max) / 2;
vertex = vertex - center;

El centrado se hace una vez en CPU antes de subir el VBO. Despues Model = T * R rota sobre el centro y aplica la traslacion.

4. Logo 42 y viewport

Cuando la ruta termina en 42.obj, el shader usa una paleta gris y el programa añade giro automatico en Y. El callback de framebuffer mantiene el dibujo adaptado al resize:

static void framebuffer_size_callback(GLFWwindow *window,
                                      int width, int height)
{
    (void)window;
    glViewport(0, 0, width, height);
}

Predicciones y ejercicios

Ejercicio 1 · centro

Si la caja va de (-4,2,0) a (6,8,10), cual es el centro?

Mostrar solucion

(1,5,5).

Ejercicio 2 · orden

Que diferencia hay entre T * R * vertex y R * T * vertex?

Mostrar solucion

El primer orden rota y despues traslada. El segundo traslada primero y puede provocar una orbita.

Ejercicio 3 · verificacion real

Ejecuta make test, make, timeout 3s ./scop resources/42.obj y timeout 3s ./scop resources/teapot2.obj.

Mostrar solucion

Los modelos arrancan, el logo reporta 42 vertices y 76 triangulos, y la salida de la tetera queda limitada a una muestra.

Errores frecuentes
  • Centrar la camara en vez de los vertices.
  • Aplicar la traslacion antes de la rotacion.
  • Ignorar delta_time.
  • Olvidar actualizar glViewport.
  • Imprimir miles de indices de una tetera.

Has aprendido que

  • La ruta OBJ puede recibirse por argumento.
  • La bounding box permite recentrar cualquier malla.
  • Model = T * R conserva el giro sobre el centro.
  • Los controles estables usan tiempo transcurrido.
  • El logo necesita grises y giro alrededor de su eje central.

Objective

Load any OBJ from the command line, center it, rotate and translate it on all three axes, and prepare the 42 logo demo with gray shades and automatic rotation around its center.

1. Input path

./scop
./scop resources/42.obj
./scop resources/teapot2.obj

The cube remains the default. Changing the model requires no rebuild.

2. Center before transforming

If an OBJ is far from the origin, direct rotation creates an orbit. center_mesh() computes the bounding-box center and subtracts it from every vertex before uploading the VBO.

center = (min + max) / 2;
vertex = vertex - center;

Then Model = T * R rotates around the center and applies translation.

Common mistakes
  • Centering the camera instead of the vertices.
  • Translating before rotating.
  • Ignoring delta_time.
  • Forgetting to update glViewport.
  • Printing thousands of teapot indices.

You have learned that

  • The OBJ path can be a command-line argument.
  • A bounding box can center any mesh.
  • Model = T * R preserves rotation around the center.
  • Stable controls use elapsed time.
  • The logo needs gray shades and rotation around its central axis.

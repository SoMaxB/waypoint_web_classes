Clase 6 · textura PPM y transicion suaveClass 6 · PPM texture and smooth transition

PPM · GL_TEXTURE_2D · sampler2D · UV · mix · delta_time
Objetivo

Aplicar una textura sin librerias externas de imagenes y alternarla suavemente con los colores por triangulo. Debes poder explicar el recorrido imagen CPU - textura GPU - sampler - fragment shader.

1. Decision tecnica

El subject solo permite librerias externas para ventana y eventos. Por eso Scop usa un cargador PPM propio en src/main.c. Acepta PPM P3 ASCII y P6 binario; la textura se puede pasar como segundo argumento.

Los OBJ disponibles no tienen vt. Como fallback inicial, el vertex shader genera UV planar desde aPos.xy:

out vec2 v_uv;
        
2. De PPM a OpenGL
El cargador valida el encabezado, dimensiones y maximo de color; lee numeros en P3 o bytes RGB en P6.
glGenTextures(1, &texture);
glBindTexture(GL_TEXTURE_2D, texture);
glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MIN_FILTER, GL_LINEAR);
glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MAG_FILTER, GL_LINEAR);
glTexImage2D(GL_TEXTURE_2D, 0, GL_RGB,
    image.width, image.height, 0,
    GL_RGB, GL_UNSIGNED_BYTE, image.pixels);
Despues de glTexImage2D, los bytes de CPU se pueden liberar.

        
3. Sampler y mezcla
uniform sampler2D u_texture;
uniform float u_texture_factor;

vec3 texture_color = texture(u_texture, v_uv).rgb;
FragColor = vec4(
    mix(face_color, texture_color, u_texture_factor), 1.0);

factor 0.0 -> solo color
factor 0.5 -> mezcla
factor 1.0 -> solo textura

        
4. Transicion independiente de FPS
T cambia texture_target. Cada frame, delta_time acerca texture_factor al objetivo. La deteccion de flanco evita multiples toggles mientras la tecla permanece pulsada.
if (texture_key_down && !texture_key_was_down)
    texture_target = !texture_target;
texture_key_was_down = texture_key_down;

texture_factor += direction * delta_time * 2.0;

Errores frecuentes
  • Usar una libreria externa de imagenes.
  • Confundir la textura GPU con los bytes de RAM.
  • Alternar en cada frame mientras se mantiene T.
  • Cambiar directamente el factor de 0 a 1.
  • Asumir UV reales cuando el OBJ no contiene vt.

Objective

Apply a texture without external image libraries and blend it smoothly with per-triangle colors. You should explain the path from CPU image to GPU texture, sampler and fragment shader.

1. Technical decision

The subject only allows external libraries for window and events. Scop therefore uses its own PPM loader in src/main.c. It accepts ASCII P3 and binary P6; the texture can be passed as the second argument.

The available OBJ files have no vt. As an initial fallback, the vertex shader generates planar UVs from aPos.xy.

2. From PPM to OpenGL

The loader validates the header and dimensions, then reads ASCII P3 values or binary P6 RGB bytes for glTexImage2D. CPU memory is released after the upload.

glGenTextures(1, &texture);
glBindTexture(GL_TEXTURE_2D, texture);
glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MIN_FILTER, GL_LINEAR);
glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MAG_FILTER, GL_LINEAR);
glTexImage2D(GL_TEXTURE_2D, 0, GL_RGB,
    image.width, image.height, 0,
    GL_RGB, GL_UNSIGNED_BYTE, image.pixels);

3. Sampler and blending

uniform sampler2D u_texture;
uniform float u_texture_factor;
vec3 texture_color = texture(u_texture, v_uv).rgb;
FragColor = vec4(mix(face_color,
    texture_color, u_texture_factor), 1.0);

factor 0.0 -> color only
factor 0.5 -> blend
factor 1.0 -> texture only

4. Frame-rate independent transition

T changes texture_target. Each frame, delta_time moves texture_factor toward that target. Edge detection prevents repeated toggles while the key is held.

Common mistakes
  • Using an external image library.
  • Confusing GPU texture with CPU image bytes.
  • Toggling every frame while holding T.
  • Jumping directly from factor 0 to 1.
  • Assuming real UVs when the OBJ has no vt.

You have learned that

  • PPM can be loaded with project-owned code.
  • glTexImage2D copies pixels to OpenGL.
  • A sampler and UVs connect the fragment shader to the texture.
  • mix interpolates color and texture.
  • delta_time makes the animation frame-rate independent.

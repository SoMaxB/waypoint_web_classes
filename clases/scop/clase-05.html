Clase 5 · color por trianguloClass 5 · per-triangle color

GL_TRIANGLES · EBO · gl_PrimitiveID · fragment shader
Objetivo

Distinguir visualmente los triangulos sin romper el EBO. Al terminar debes poder explicar por que un color por vertice no basta cuando hay vertices compartidos y como gl_PrimitiveID mantiene un color constante por triangulo.

1. El requisito

El cubo ya se ve en perspectiva, pero todas sus caras usan el mismo naranja. El subject permite distinguir la cara OBJ o, si se triangula, cada triangulo.

El VBO reutiliza vertices mediante un EBO. Un vertice compartido no puede ser rojo para una cara y azul para otra al mismo tiempo.

SolucionCosteDecision
Duplicar verticesMas memoriaUtil para UV distintas
Una draw call por caraMas organizacionPosible
gl_PrimitiveIDSin datos extraElegida ahora

2. Color por primitive

En un draw de GL_TRIANGLES, gl_PrimitiveID identifica el triangulo actual. Todos sus fragmentos reciben el mismo identificador, asi que el color no se interpola dentro de la cara.

void main()
{
    float id = float(gl_PrimitiveID);
    vec3 color = vec3(
        0.55 + 0.35 * sin(id * 1.7),
        0.55 + 0.35 * sin(id * 1.7 + 2.1),
        0.55 + 0.35 * sin(id * 1.7 + 4.2)
    );
    FragColor = vec4(color, 1.0);
}

La paleta es determinista: el mismo triangulo conserva su color entre frames.

3. El EBO sigue definiendo las caras

8 vertices -> 6 caras -> 12 triangulos -> 36 indices

glDrawElements(GL_TRIANGLES, (GLsizei)mesh.i_count,
               GL_UNSIGNED_INT, (void *)0);

Una cara cuadrilateral se convierte en dos primitives. Por eso esta clase distingue triangulos, que es una opcion valida del subject.

Errores frecuentes
  • Confundir la cara OBJ original con los triangulos resultantes.
  • Eliminar el EBO al anadir colores.
  • Usar colores aleatorios por frame y producir parpadeo.
  • Creer que gl_PrimitiveID identifica poligonos originales de cualquier numero de vertices.

  • Los vertices compartidos no bastan para colores distintos por cara.
  • El EBO agrupa indices de tres en tres con GL_TRIANGLES.
  • gl_PrimitiveID identifica el triangulo rasterizado.
  • El color constante por primitive no necesita datos adicionales en el VBO.

Objective

Make triangles visually distinct without breaking the existing EBO. By the end you should explain why per-vertex color is insufficient with shared vertices and how gl_PrimitiveID keeps one color across a triangle.

1. The requirement

The cube is already rendered in perspective, but every face uses the same orange. The subject allows coloring each OBJ face or, after triangulation, each triangle.

The EBO reuses vertices. A shared vertex cannot be red for one face and blue for another at the same time.

SolutionCostDecision
Duplicate verticesMore memoryUseful for different UVs
One draw call per faceMore organizationPossible
gl_PrimitiveIDNo extra dataChosen now

2. Color per primitive

In a GL_TRIANGLES draw, gl_PrimitiveID identifies the current triangle. All its fragments receive the same identifier, so the color stays flat inside the triangle.

float id = float(gl_PrimitiveID);
vec3 color = vec3(
    0.55 + 0.35 * sin(id * 1.7),
    0.55 + 0.35 * sin(id * 1.7 + 2.1),
    0.55 + 0.35 * sin(id * 1.7 + 4.2)
);
FragColor = vec4(color, 1.0);

The palette is deterministic, so a triangle keeps its color between frames.

3. The EBO still defines the faces

8 vertices -> 6 faces -> 12 triangles -> 36 indices

glDrawElements(GL_TRIANGLES, (GLsizei)mesh.i_count,
               GL_UNSIGNED_INT, (void *)0);

A quadrilateral face becomes two primitives. This class therefore colors triangles, which is allowed by the subject.

Common mistakes
  • Confusing the original OBJ face with the triangles produced by triangulation.
  • Removing the EBO when adding colors.
  • Using random colors every frame and causing flicker.
  • Assuming gl_PrimitiveID identifies original polygons of any size.

You have learned that

  • Shared vertices are insufficient for distinct per-face colors.
  • An EBO groups indices in threes with GL_TRIANGLES.
  • gl_PrimitiveID identifies the rasterized triangle.
  • Flat per-primitive color needs no extra VBO data.

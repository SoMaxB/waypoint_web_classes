Clase 6 · ft_strcpy y ft_strcmpClass 6 · ft_strcpy and ft_strcmp

rdi rsi · rax · movzx · unsigned char · terminator
Objetivo

Dominar funciones con dos punteros y la semántica de unsigned char. Al terminar debes poder explicar por qué ft_strcpy guarda el dst original, por qué debe copiar el \0, y por qué ft_strcmp debe cargar bytes con movzx y devolver byte1 - byte2 como unsigned char. Ambas son hojas: no tocan pila.

1. Contratos

char *ft_strcpy(char *dst, const char *src);
int   ft_strcmp(const char *s1, const char *s2);
ft_strcpy: rdi = dst, rsi = src, retorno rax = dst original
ft_strcmp: rdi = s1,  rsi = s2,  retorno eax = diff unsigned

2. ft_strcpy: copiar incluido \0

char *ft_strcpy(char *dst, const char *src) {
    char *orig = dst;
    while ((*dst++ = *src++) != '\0')
        ;
    return orig;
}

Invariante: todo lo copiado hasta i-1 coincide y aún no se ha copiado \0 salvo la última iteración.

default rel
section .text
global ft_strcpy
ft_strcpy:
    mov     rax, rdi
.loop:
    mov     dl, byte [rsi]
    mov     byte [rdi], dl
    test    dl, dl
    je      .done
    inc     rdi
    inc     rsi
    jmp     .loop
.done:
    ret
section .note.GNU-stack noalloc noexec nowrite progbits

dl (byte bajo de rdx) es caller-saved. test dl,dl fija ZF. Si haces je antes de mov [rdi],dl, no copias el terminador → strlen(dst) lee basura.

3. ft_strcmp: unsigned char

C debe comparar como unsigned char:

s1 = {0xFF,0} // 255 unsigned, -1 signed
s2 = {0x01,0} // 1
signed: -1 -1 = -2 (<0 mal)  unsigned: 255-1=254 (>0 bien)
int ft_strcmp(const char *s1, const char *s2) {
    while (1) {
        unsigned char c1 = *s1, c2 = *s2;
        if (c1 != c2) return c1 - c2;
        if (c1 == '\0') return 0;
        s1++; s2++;
    }
}
default rel
section .text
global ft_strcmp
ft_strcmp:
.loop:
    movzx   eax, byte [rdi]
    movzx   ecx, byte [rsi]
    cmp     al, cl
    jne     .diff
    test    al, al
    je      .equal
    inc     rdi
    inc     rsi
    jmp     .loop
.diff:
    sub     eax, ecx
    ret
.equal:
    xor     eax, eax
    ret
section .note.GNU-stack noalloc noexec nowrite progbits

movzx extiende con ceros (unsigned). sub eax,ecx da el diff exacto que usa libc aquí.

5. Predicciones y ejercicios

Ejercicio 1 · strcpy paso a paso

src="Hi" en 0x9000, dst 0x8000, rax=0x8000. ¿Qué se escribe cada iteración?

Mostrar solución 
iter1 dl=0x48->[0x8000]=0x48 rdi=0x8001 rsi=0x9001
iter2 dl=0x69->[0x8001]=0x69 rdi=0x8002 rsi=0x9002
iter3 dl=0x00->[0x8002]=0x00 je .done ret 0x8000
Ejercicio 2 · strcpy sin \0

¿Qué pasa si je .done va antes de mov [rdi],dl?

Mostrar solución 
No copias \0, dst sin terminar, strlen lee basura. El test X falla.
Ejercicio 3 · signed vs unsigned

{0xFF} vs {0x01}: signed vs unsigned.

Mostrar solución 
signed -1-1=-2 (<0) mal; unsigned 255-1=254 (>0) bien
Ejercicio 4 · prefijo

"abc" vs "abcd" en i=3.

Mostrar solución 
c1=0x00 c2='d'(0x64) → 0-100=-100 (<0)
Ejercicio 5 · retorno strcmp

¿Debe devolver solo -1/0/1?

Mostrar solución 
No, c1-c2 exacto (-100, 254, etc.). -1/0/1 pierde el test exacto.
Ejercicio 6 · guardar dst

¿Por qué mov rax,rdi al inicio?

Mostrar solución 
rdi avanza; al final vale \0. Solo rax inicial conserva dst original.
Errores frecuentes
  • Devolver rdi avanzado en strcpy.
  • No copiar \0.
  • Usar movsx en strcmp.
  • Comparar rdi vs rsi en lugar de [rdi] vs [rsi].
  • Devolver -1/0/1.

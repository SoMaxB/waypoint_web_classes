Clase 2 · registros e instruccionesClass 2 · registers and instructions

rdi · rax · dl · mov · lea · cmp
Objetivo

Entender qué guardan los registros, distinguir una dirección de su contenido en memoria y seguir un bucle corto instrucción por instrucción. Al terminar, debes poder explicar cómo se recorre una cadena C y por qué ft_strlen no cuenta su terminador.

1. Registros y significado de los valores

Un registro es almacenamiento pequeño y rápido dentro de la CPU. Puede contener un número, una dirección o un byte. El registro no conoce el significado del valor: lo determina la instrucción que lo utiliza.

Usaremos estos tres registros como modelo:

rdi: dirección del byte que estamos leyendo
rax: contador de caracteres
dl:  último byte leído

Si una cadena "Hi" está en memoria:

DirecciónContenido
0x10000x48 'H'
0x10010x69 'i'
0x10020x00 '\0'

y rdi = 0x1000, entonces:

rdi       = 0x1000    dirección
[rdi]     = 0x48      contenido de esa dirección

Los corchetes indican un acceso a memoria. Sin ellos se usa el valor que ya contiene el registro.

mov rax, rdi     ; copia 0x1000, una dirección
mov al, [rdi]    ; lee 0x48, un byte de memoria

2. Familias de registros

Un registro de 64 bits puede nombrarse por partes:

rax: 64 bits
eax: 32 bits bajos de rax
ax:  16 bits bajos de rax
al:  8 bits bajos de rax

Para recorrer cadenas se cargan bytes en registros de 8 bits como al o dl. Un contador de longitud se mantiene en un registro de 64 bits como rax.

3. mov, aritmética y lea

mov copia un valor. No modifica la fuente:

mov rdi, 0x1000
mov rax, rdi

Después ambas variables de registro contienen 0x1000.

Para avanzar una posición de una cadena se suma uno a la dirección:

add rdi, 1

También se puede escribir:

inc rdi

dec resta uno. Estas instrucciones cambian solamente su operando:

inc rax        ; no modifica rdi ni dl

lea calcula una dirección, pero no accede a memoria:

lea rax, [rdi + 2]

Con rdi = 0x1000, el resultado es rax = 0x1002. A diferencia de mov al, [rdi], no lee el contenido de esa dirección.

4. Comparación, flags y saltos

cmp a, b compara conceptualmente a - b y actualiza flags, pero no modifica a ni b.

cmp dl, 0
je fin

Si dl es cero, se activa el flag cero (ZF = 1) y je salta a fin. Si no es cero, el salto no se realiza y la CPU ejecuta la instrucción siguiente.

Los saltos iniciales más importantes son:

SaltoSignificado
jesalta si los valores eran iguales
jnesalta si los valores eran distintos
jbsalta si el primer valor es menor sin signo
jasalta si el primer valor es mayor sin signo

Los nombres de las etiquetas no alteran el salto. je fin solo salta si la condición de igualdad se cumple, aunque la etiqueta se llame fin.

5. Recorrer una cadena C

Este bucle representa la lógica de strlen:

mov rax, 0

bucle:
    mov dl, [rdi]
    cmp dl, 0
    je fin
    inc rax
    inc rdi
    jmp bucle

fin:

Para la cadena "Hi\0", el seguimiento correcto es:

Pasordidl leído¿Es '\0'?rax despuésrdi después
10x10000x48 ('H')No10x1001
20x10010x69 ('i')No20x1002
30x10020x00 ('\0')Sí20x1002

Al terminar:

rdi = 0x1002
rax = 2
dl  = 0x00

El terminador se lee para saber cuándo parar, pero no se cuenta: je fin se realiza antes de inc rax.

Ejercicio 4

Errores frecuentes
  • Confundir rdi, la dirección, con [rdi], el contenido de la dirección.
  • Creer que una instrucción como inc rax modifica también registros que no menciona.
  • Avanzar el puntero o cargar el siguiente byte antes de que esas instrucciones se ejecuten realmente.
  • Contar \0 como un carácter de la cadena.
  • Creer que todos los flags quedan a cero cuando cmp compara dos valores iguales. En ese caso, el flag relevante ZF vale uno.
  • Intentar interpretar todo el bucle de una vez. Es más fiable seguir una línea por vez: qué registro cambia, qué valor toma y si hay salto.

Objective

Understand what registers hold, tell an address apart from its contents in memory, and trace a short loop instruction by instruction. By the end you must be able to explain how a C string is walked and why ft_strlen does not count its terminator.

1. Registers and the meaning of values

A register is small, fast storage inside the CPU. It can hold a number, an address or a byte. The register does not know the meaning of the value: the instruction using it decides.

We will use these three registers as a model:

rdi: address of the byte we are reading
rax: character counter
dl:  last byte read

If the string "Hi" is in memory:

AddressContents
0x10000x48 'H'
0x10010x69 'i'
0x10020x00 '\0'

and rdi = 0x1000, then:

rdi       = 0x1000    address
[rdi]     = 0x48      contents of that address

Brackets mean a memory access. Without them, the value the register already holds is used.

mov rax, rdi     ; copies 0x1000, an address
mov al, [rdi]    ; reads 0x48, one byte of memory

2. Register families

A 64-bit register can be named by parts:

rax: 64 bits
eax: low 32 bits of rax
ax:  low 16 bits of rax
al:  low 8 bits of rax

To walk strings you load bytes into 8-bit registers like al or dl. A length counter lives in a 64-bit register like rax.

3. mov, arithmetic and lea

mov copies a value. It does not modify the source:

mov rdi, 0x1000
mov rax, rdi

Afterwards both register variables hold 0x1000.

To advance one position through a string, add one to the address:

add rdi, 1

You can also write:

inc rdi

dec subtracts one. These instructions only change their operand:

inc rax        ; does not modify rdi or dl

lea computes an address but does not access memory:

lea rax, [rdi + 2]

With rdi = 0x1000, the result is rax = 0x1002. Unlike mov al, [rdi], it does not read the contents of that address.

4. Comparison, flags and jumps

cmp a, b conceptually compares a - b and updates flags, but does not modify a or b.

cmp dl, 0
je fin

If dl is zero, the zero flag is set (ZF = 1) and je jumps to fin. If not, the jump does not happen and the CPU executes the next instruction.

The most important beginner jumps are:

JumpMeaning
jejumps if the values were equal
jnejumps if the values were different
jbjumps if the first value is lower, unsigned
jajumps if the first value is higher, unsigned

Label names do not change the jump. je fin only jumps if the equality condition holds, even if the label is named fin.

5. Walking a C string

This loop represents the logic of strlen:

mov rax, 0

bucle:
    mov dl, [rdi]
    cmp dl, 0
    je fin
    inc rax
    inc rdi
    jmp bucle

fin:

For the string "Hi\0", the correct trace is:

Steprdidl readIs it '\0'?rax afterrdi after
10x10000x48 ('H')No10x1001
20x10010x69 ('i')No20x1002
30x10020x00 ('\0')Yes20x1002

At the end:

rdi = 0x1002
rax = 2
dl  = 0x00

The terminator is read to know when to stop, but it is not counted: je fin happens before inc rax.

Common mistakes
  • Confusing rdi, the address, with [rdi], the contents of that address.
  • Thinking an instruction like inc rax also changes registers it does not mention.
  • Advancing the pointer or loading the next byte before those instructions actually run.
  • Counting \0 as a character of the string.
  • Thinking all flags go to zero when cmp compares two equal values. In that case the relevant flag ZF is one.
  • Trying to interpret the whole loop at once. It is more reliable to follow one line at a time: which register changes, what value it takes, and whether there is a jump.

Glosario

referencia · no memorizar de golpe

Este documento reúne las siglas, palabras e instrucciones que aparecen durante el proyecto. No hace falta memorizarlo de una vez: úsalo como referencia mientras lees código o haces ejercicios.This document collects the acronyms, words and instructions that come up during the project. You do not need to memorize it all at once: use it as a reference while reading code or doing exercises.

Notación y memoriaNotation and memory

TermSignificado literalLiteral meaningDescripción de usoUsage description
0xPrefijo hexadecimalHex prefixIndica que un número está escrito en base 16: 0x48 es 72 en decimal y 'H' en ASCII.Indicates a number written in base 16: 0x48 is 72 in decimal and 'H' in ASCII.
[]Acceso a memoriaMemory access[rdi] significa "el contenido situado en la dirección guardada en rdi". Sin corchetes, rdi es la dirección misma.[rdi] means "the contents located at the address stored in rdi". Without brackets, rdi is the address itself.
\0Byte nuloNull byteByte con valor cero. Termina una cadena C; no es el carácter visible '0', cuyo valor es 0x30.Byte with value zero. Terminates a C string; it is not the visible character '0', whose value is 0x30.
punteroPointerValor que contiene una dirección de memoria.Value that holds a memory address.
desreferenciarDereferenceLeer o escribir el contenido de la dirección almacenada en un puntero, por ejemplo con [rdi].Read or write the contents of the address stored in a pointer, for example with [rdi].
offsetDesplazamientoOffsetNúmero añadido a una dirección, como en [rdi + 2]. En una estructura permite llegar a un campo concreto.Number added to an address, like in [rdi + 2]. In a struct it lets you reach a specific field.
little-endianExtremo pequeño primeroLeast significant byte firstOrden de memoria en x86-64 para valores de varios bytes: el byte menos significativo ocupa la dirección menor.Memory order in x86-64 for multi-byte values: the least significant byte occupies the lowest address.

Instrucciones básicasBasic instructions

TermSignificado literalLiteral meaningDescripción de usoUsage description
movMoveCopia un valor del origen al destino. No modifica el origen. mov al, [rdi] lee un byte de memoria.Copies a value from source to destination. It does not modify the source. mov al, [rdi] reads one memory byte.
leaLoad Effective AddressCalcula una dirección o una suma de direcciones sin leer memoria. lea rax, [rdi + 2] deja rdi + 2 en rax.Computes an address or address sum without reading memory. lea rax, [rdi + 2] puts rdi + 2 in rax.
addAddSuma el segundo operando al primero: add rax, 1.Adds the second operand to the first: add rax, 1.
subSubtractResta el segundo operando al primero: sub rsp, 8.Subtracts the second operand from the first: sub rsp, 8.
incIncrementSuma uno al operando: inc rax.Adds one to the operand: inc rax.
decDecrementResta uno al operando: dec rax.Subtracts one from the operand: dec rax.
cmpCompareCompara conceptualmente dos valores mediante una resta, actualiza flags y no modifica los operandos.Conceptually compares two values with a subtraction, updates flags and does not modify the operands.
testTestHace un AND lógico solo para actualizar flags. Se ve como alternativa frecuente a cmp reg, 0.Does a logical AND only to update flags. Often seen as an alternative to cmp reg, 0.
jmpJumpSalto incondicional a una etiqueta: jmp bucle.Unconditional jump to a label: jmp bucle.
callCallGuarda una dirección de retorno en la pila y salta a una función.Saves a return address on the stack and jumps to a function.
retReturnRecupera de la pila la dirección guardada por call y vuelve al llamador.Retrieves from the stack the address saved by call and returns to the caller.
pushPushReserva 8 bytes en la pila y guarda allí un valor.Reserves 8 bytes on the stack and stores a value there.
popPopLee un valor desde la pila y libera esos 8 bytes.Reads a value from the stack and frees those 8 bytes.
syscallSystem callEntra al kernel Linux para pedir operaciones como read o write.Enters the Linux kernel to request operations like read or write.

Flags y saltos condicionalesFlags and conditional jumps

Un flag es un bit de estado que deja una instrucción como cmp. Un salto condicional consulta esos bits justo después.A flag is a status bit left by an instruction like cmp. A conditional jump reads those bits right after.

TermSignificado literalLiteral meaningDescripción de usoUsage description
ZFZero FlagVale uno si el resultado de una comparación u operación es cero.Is one if the result of a comparison or operation is zero.
CFCarry FlagIndica acarreo o préstamo en aritmética sin signo; lo usan comparaciones sin signo.Indicates carry or borrow in unsigned arithmetic; used by unsigned comparisons.
SFSign FlagRefleja el bit de signo de un resultado.Reflects the sign bit of a result.
OFOverflow FlagIndica que un cálculo con signo no cabe en el tamaño del operando.Indicates a signed calculation that does not fit in the operand size.
je / jzJump if Equal / ZeroSalta cuando los valores comparados son iguales; requiere ZF = 1.Jumps when the compared values are equal; requires ZF = 1.
jne / jnzJump if Not EqualSalta cuando los valores comparados son distintos.Jumps when the compared values are different.
jbJump if BelowSalta si el primer valor es menor que el segundo como entero sin signo. Útil al comparar bytes.Jumps if the first value is lower than the second as an unsigned integer. Useful when comparing bytes.
jaJump if AboveSalta si el primer valor es mayor que el segundo como entero sin signo.Jumps if the first value is higher than the second as an unsigned integer.
jlJump if LessSalta si el primer valor es menor como entero con signo.Jumps if the first value is lower as a signed integer.
jgJump if GreaterSalta si el primer valor es mayor como entero con signo.Jumps if the first value is higher as a signed integer.

Regla de lecturaReading rule

Cuando encuentres una instrucción nueva, localiza sus operandos y pregúntate:When you meet a new instruction, locate its operands and ask yourself:

1. ¿Qué valor representa cada registro ahora?
2. ¿Hay corchetes? Si los hay, ¿qué dirección se lee o escribe?
3. ¿Qué registro, memoria o flag cambia?
4. Si hay un salto, ¿se cumple su condición?

Esta secuencia evita intentar entender todas las siglas de una vez.This sequence keeps you from trying to understand every acronym at once.

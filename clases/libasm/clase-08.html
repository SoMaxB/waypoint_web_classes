Clase 8 · ft_write, ft_read y errnoClass 8 · ft_write, ft_read and errno

rax 1/0 · syscall · jl error · __errno_location · wrt ..plt · dword
Objetivo

Implementar los dos wrappers que deben replicar exactamente retorno y errno de libc. Al terminar explicas por qué el kernel devuelve -EBADF, cómo lo conviertes en -1 y errno=9, por qué necesitas __errno_location con wrt ..plt y pila alineada, y demuestras con strace que éxito, count=0, parcial, EOF y errores coinciden con write(2)/read(2).

1. Contratos

ssize_t ft_write(int fd, const void *buf, size_t count);
ssize_t ft_read(int fd, void *buf, size_t count);
rdi=fd rsi=buf rdx=count → rax=retorno ssize_t
read=0 write=1 en rax

2. Flujo

rax = n; syscall; cmp rax,0; jl .error; ret
.error: neg rax; push rax; call __errno_location wrt ..plt; pop rdi; mov dword [rax],edi; mov rax,-1; ret

Kernel ≥0 éxito, [-4095,-1] error. Para read/write basta jl. syscall destruye rcx/r11.

3. errno

extern __errno_location
call __errno_location wrt ..plt  ; R_X86_64_PLT32
mov dword [rax], edi             ; 32 bits

Thread-local, wrt ..plt para PIE, preservar error con push/pop (alinea: entry 8 → push 0 → call).

4. ft_write

default rel
section .text
global ft_write
extern __errno_location
ft_write:
    mov     rax, 1
    syscall
    cmp     rax, 0
    jl      .error
    ret
.error:
    neg     rax
    push    rax
    call    __errno_location wrt ..plt
    pop     rdi
    mov     dword [rax], edi
    mov     rax, -1
    ret
section .note.GNU-stack noalloc noexec nowrite progbits

5. ft_read

mov rax,0; syscall; cmp rax,0; jl .error; ret  // mismo .error

No añade \0, parcial no es error, 0 con count>0 es EOF.

6. Verificación

nasm -f elf64 ft_write.s -o ft_write.o && cc -Wall -Wextra -Werror main.c ft_write.o -o tester
readelf -h tester # DYN
nm -g ft_write.o  # T ft_write U __errno_location
objdump -dr       # R_X86_64_PLT32
strace -e trace=read,write ./tester

Mostrar solución

Mostrar solución

Ejercicio 5 · dword

¿Por qué dword [rax],edi?

Mostrar solución 
errno es int 32b, qword pisaría memoria
Ejercicio 6 · PLT

wrt ..plt

Mostrar solución 
PLT32 para PIE, sin él reloc incompatible
Ejercicio 7 · pila

entry rsp%16==8, ¿push?

Mostrar solución 
push → 0 antes de call, ABI exige 0
Errores frecuentes
  • rcx para arg4 (es r10).
  • extern int errno.
  • mov [rax],rdi 64b.
  • Olvidar wrt ..plt.
  • No preservar error.
  • Desalinear pila.
  • count=0 como error.

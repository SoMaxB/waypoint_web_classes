Modelo de concurrenciaConcurrency model

TermSignificado literalLiteral meaningDescripción de usoUsage description
procesoProcessInstancia de un programa en ejecución con su propia memoria y sus propios descriptores.Instance of a running program with its own memory and file descriptors.
hiloThreadLínea de ejecución dentro de un proceso. Los hilos de un mismo proceso comparten memoria.Line of execution inside a process. Threads of the same process share memory.
concurrenciaConcurrencyCapacidad de ejecutar varias secuencias de código superpuestas en el tiempo.Ability to run several code sequences overlapping in time.
interleavingInterleavingOrden concreto en el que se entrelazan las instrucciones de varios hilos. No es determinista.Concrete order in which the instructions of several threads interleave. Not deterministic.
condición de carreraRace conditionResultado erróneo que depende del orden en que se ejecutan los hilos.Wrong result that depends on the order in which threads run.
sección críticaCritical sectionFragmento que accede a un recurso compartido y no debe ejecutarse en paralelo con otro que toque el mismo recurso.Piece of code accessing a shared resource that must not run in parallel with another one touching the same resource.
operación atómicaAtomic operationOperación que se observa como indivisible desde fuera del hilo que la ejecuta.Operation observed as indivisible from outside the thread running it.
planificadorSchedulerComponente del kernel que decide qué hilo se ejecuta y cuándo.Kernel component that decides which thread runs and when.
bloqueoBlockingEstado de un hilo que espera hasta que una condición se cumpla, sin consumir CPU.State of a thread waiting until a condition holds, without burning CPU.
deadlockDeadlockEspera cíclica de recursos: dos o más hilos esperan cosas que solo los otros liberan y ninguno avanza.Cyclic wait on resources: two or more threads wait for things only the others release and none makes progress.
starvationInaniciónUn hilo nunca obtiene el recurso porque otros siempre se adelantan.A thread never gets the resource because others keep getting ahead.

Semáforos POSIXPOSIX semaphores

TermSignificado literalLiteral meaningDescripción de usoUsage description
semáforoSemaphoreContador con operaciones atómicas de espera y señalización.Counter with atomic wait and signal operations.
sem_tSemaphore typeTipo opaco declarado en semaphore.h que representa un semáforo.Opaque type declared in semaphore.h that represents a semaphore.
sem_initSemaphore initializeInicializa un semáforo sin nombre con un valor inicial y un ámbito.Initializes an unnamed semaphore with an initial value and a scope.
sem_waitSemaphore waitDecrementa el contador; bloquea al hilo si el valor es 0. Atómico.Decrements the counter; blocks the thread if the value is 0. Atomic.
sem_postSemaphore postIncrementa el contador; desbloquea un hilo si alguno esperaba. Nunca bloquea.Increments the counter; unblocks a thread if one was waiting. Never blocks.
sem_destroySemaphore destroyLibera los recursos asociados a un semáforo inicializado.Frees the resources associated with an initialized semaphore.
psharedProcess-sharedArgumento de sem_init: 0 para hilos del mismo proceso, 1 para procesos distintos (requiere memoria compartida).Argument of sem_init: 0 for threads of the same process, 1 for different processes (requires shared memory).
mutexMutual exclusionCerradura de exclusión mutua con owner: solo el hilo que la adquirió puede liberarla. Caso particular de semáforo binario.Mutual-exclusion lock with an owner: only the thread that acquired it can release it. Special case of a binary semaphore.
productor-consumidorProducer-consumerPatrón con un productor que crea datos y un consumidor que los usa, coordinados por un buffer y contadores.Pattern with a producer creating data and a consumer using it, coordinated by a buffer and counters.

Regla de lecturaReading rule

Cuando leas un fragmento concurrente, pregúntate:When you read a concurrent snippet, ask yourself:

1. ¿Qué recurso comparten los hilos?
2. ¿Alguien lo escribe? Si no, no hay carrera.
3. ¿Qué operaciones son atómicas y cuáles no?
4. ¿Cada wait tiene su post (o su lock su unlock)?
5. ¿Puede un hilo quedarse bloqueado mientras sostiene lo que otro necesita? (deadlock)

Esta secuencia evita intentar entender toda la API de una vez.This sequence keeps you from trying to understand the whole API at once.

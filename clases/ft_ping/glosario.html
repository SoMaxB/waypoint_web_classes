Notación y redNotation and networking

TermSignificado literalLiteral meaningDescripción de usoUsage description
ICMPInternet Control Message ProtocolProtocolo de control usado por ping. Transporta los Echo Request y Echo Reply; viaja sobre IP, sin puertos.Control protocol used by ping. It carries Echo Requests and Echo Replies over IP, without ports.
Echo RequestPetición de ecoEcho requestMensaje ICMP que ping envía (tipo 8, código 0) para comprobar si un host responde.ICMP message ping sends (type 8, code 0) to check whether a host replies.
Echo ReplyRespuesta de ecoEcho replyMensaje ICMP que el host devuelve (tipo 0, código 0) cuando recibe un Echo Request.ICMP message the host returns (type 0, code 0) when it receives an Echo Request.
typeTipo de mensaje ICMPICMP message typeCampo de la cabecera que identifica el mensaje: 8 = Echo Request, 0 = Echo Reply.Header field identifying the message: 8 = Echo Request, 0 = Echo Reply.
codeCódigo de mensaje ICMPICMP message codeCampo que matiza el tipo; para eco vale 0.Field that qualifies the type; it is 0 for echo.
checksumSuma de comprobaciónChecksumValor calculado sobre todo el paquete ICMP, con el campo a cero durante el cálculo, para detectar corrupción.Value computed over the whole ICMP packet, with the field zeroed during the calculation, to detect corruption.
identifierIdentificadorIdentifierCampo que asocia un Echo Request con su Reply; ping suele derivarlo del PID.Field that pairs an Echo Request with its Reply; ping usually derives it from the PID.
sequenceNúmero de secuenciaSequence numberCampo que numera cada Echo Request enviado, para emparejar respuestas.Field numbering each sent Echo Request, to pair replies.
TTLTime To LiveCampo de la cabecera IP que limita los saltos de un paquete; se reduce en cada salto y al llegar a cero el paquete se descarta.IP header field limiting how many hops a packet may cross; it decreases each hop and at zero the packet is dropped.
RTTRound-Trip TimeTiempo entre el envío de un Echo Request y la recepción de su Reply.Time between sending an Echo Request and receiving its Reply.
FQDNFully Qualified Domain NameNombre de host completo con todos sus dominios, por ejemplo example.com; hay que resolverlo a una dirección IP.Complete host name with all its domains, e.g. example.com; it must be resolved to an IP address.

Regla de lecturaReading rule

Cuando leas una función o syscall nueva, pregúntate:When you meet a new function or syscall, ask yourself:

1. ¿Qué parámetros recibe y en qué orden?
2. ¿Qué estructura o buffer leo o escribo?
3. ¿El valor es de red (big-endian) o del host (little-endian)? ¿Aplico htons/ntohs?
4. ¿Puede fallar? ¿Cómo se detecta el fallo y cómo se maneja sin salir inesperadamente?

Esta secuencia evita intentar entender todas las siglas de una vez.This sequence keeps you from trying to understand every acronym at once.
